# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of AgentIAM seriously. If you believe you have found a security vulnerability, please report it to us as follows:

1. **Do not open a public issue.**
2. Send an email to **security@agentiam.io** with details of the vulnerability.
3. We will acknowledge your report within 48 hours and provide a timeline for a fix.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We appreciate your help in keeping AgentIAM secure.

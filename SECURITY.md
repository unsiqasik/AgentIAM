## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

We take the security of AgentIAM seriously. If you discover a vulnerability, please help us by reporting it responsibly.

### How to report a vulnerability

If you believe you have found a security vulnerability, please send a detailed report to **security@agentiam.io** (or use GitHub's Private Vulnerability Reporting if enabled).

Your report should include:
- **Description**: A detailed description of the vulnerability.
- **Impact**: The potential impact of the vulnerability.
- **Reproduction**: Step-by-step instructions or a Proof of Concept (PoC) script to reproduce the issue.
- **Mitigation**: Any suggestions for fixing the issue.

### Our Response Process

1. **Acknowledgment**: We will acknowledge your report within 48 business hours.
2. **Investigation**: We will investigate and confirm the vulnerability.
3. **Fix**: If confirmed, we will develop a fix and test it.
4. **Disclosure**: We will coordinate the public disclosure after the fix is released.

## Security Best Practices for Users

- Always use the latest version of AgentIAM.
- Follow the [Principle of Least Privilege](https://en.wikipedia.org/wiki/Principle_of_least_privilege) when defining policies.
- Regularly audit your agent activity logs.
- Secure your database and environment variables.

## Title
[Frontend] Implement policy editor with YAML syntax highlighting

## Problem Statement
Currently, policy editing is likely done via a simple text area or basic input fields. This makes it difficult to read and write complex YAML policies, and lacks validation/linting during the editing process.

## Why It Matters
A high-quality policy editor reduces human error and improves the developer experience for security administrators. Syntax highlighting and automatic indentation make policies much easier to manage.

## Current Behavior
Basic text input for policy content.

## Expected Behavior
A rich code editor (Monaco or CodeMirror) integrated into the Policy creation/edit page with YAML syntax highlighting, line numbers, and basic indentation support.

## Proposed Solution
1. Install `@monaco-editor/react` or `react-codemirror`.
2. Replace the current policy text area with the code editor component.
3. Configure the editor for `yaml` language support.

## Acceptance Criteria
- Policy editor displays YAML with proper syntax highlighting.
- Editor supports standard features like line numbers and auto-indentation.
- The edited content is correctly saved back to the state and sent to the API.
